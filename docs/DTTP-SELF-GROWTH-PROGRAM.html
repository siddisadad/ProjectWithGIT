00How to use this program

Full-stack reference material provides a strong foundation. It is not the entire DTTP curriculum. Use it as the Full-Stack Knowledge Reference, then apply it through Deshmukh Technologies tracks and real projects.

Do not ask trainees to study the reference as one large syllabus. Organize growth into ten levels, then combine each level with Java/Spring Boot or Python/FastAPI, React/TypeScript, SQL, GitHub, Docker, CI/CD, AWS, and real Deshmukh Technologies work.
  1. Web Fundamentals
  2. Frontend Fundamentals
  3. React + TypeScript
  4. HTTP + REST + Web APIs
  5. Java / Python Backend
  6. Databases
  7. Architecture
  8. Testing + Security + Performance
  9. Git + Docker + CI/CD + Cloud
  10. Agile + Professional Engineering

The destination is a self-directed full-stack developer who can build, test, debug, explain, document, and maintain software.

01Level 1 — Web Fundamentals

These are the starting concepts for understanding full-stack development.

Client & serverURLs, domains, IP addressesWeb application structureHTMLCSSJavaScriptServer-side logicFull-stack conceptsDevelopment tools
A trainee who cannot explain how a browser request reaches a server is not ready for React or Spring Boot.

02Level 2 — Frontend Engineering

Progress from HTML, CSS and JavaScript into the DOM, Fetch/API usage, and accessibility.

Structure & style

  • HTML elements and forms
  • CSS selectors and specificity
  • Flexbox
  • CSS Grid

Behavior & access

  • JavaScript variables, types, functions
  • Error handling, objects, arrays
  • DOM, Fetch API, Web APIs
  • Accessibility

05Level 5 — Backend Development

Specialize server-side concepts into the Deshmukh Technologies tracks. Trainees are not required to learn every backend language in the reference material.

Java track

  1. Java
  2. Spring Boot
  3. REST
  4. JPA / Hibernate
  5. Spring Security

Python track

  1. Python
  2. FastAPI
  3. Pydantic
  4. SQLAlchemy
  5. Authentication

06Level 6 — Database Engineering

This is a major self-growth area. SQL + MySQL / PostgreSQL is mandatory. NoSQL is introduced later.

Relational — mandatory

  • Tables and relationships
  • SQL
  • ORM
  • Transactions
  • Query design

Non-relational — later

  • Key-value
  • Document
  • Graph
  • Column-oriented databases
ORM knowledge must not replace SQL knowledge.

07Level 7 — Architecture

This is where trainees move from developer thinking to engineer thinking. Study architectural models, but understand why architecture changes.

Layered architectureClient-serverMulti-tierMonolithSOAMicroservicesComponent-basedMicrofrontendsMessagingMVCMVPMVVM

DTTP architecture principle

Do not teach microservices first. Teach Monolith → Layered Architecture → Modular Monolith → Distributed Systems → Microservices.

08Level 8 — Testing, Security & Performance

These three become permanent self-growth subjects.

Testing

  • Automated testing
  • Unit and integration tests
  • TDD and coverage
  • Test doubles, spies, stubs, mocks

Security

  • Injection, XSS, access control
  • Authentication and authorization
  • Sensitive data, TLS / HTTPS
  • CORS, CSP, token authentication

Performance

  • Measure before optimizing
  • Connection and image optimization
  • Server- and client-side caching
  • Minification, compression, lazy loading, preloading
Measure performance before optimizing it.
