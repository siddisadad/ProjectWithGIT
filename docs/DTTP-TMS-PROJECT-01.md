# DTTP — Trainee Management System (TMS)

**Real-Time Project 01**

Print: [`DTTP-TMS-PROJECT-01.pdf`](./DTTP-TMS-PROJECT-01.pdf)

---

## Purpose

Build a simple system to manage Deshmukh Technologies trainees.

---

## Technology

- Python
- FastAPI
- MySQL
- React
- Git & GitHub
- Postman

---

## Main features

1. **Login**
   - Admin
   - Mentor
   - Trainee
2. **Trainee management**
   - Add trainee
   - View trainees
   - Edit trainee
   - Deactivate trainee
3. **Batch management**
   - Create batch
   - Assign trainees
   - Assign mentor
4. **Attendance**
   - Present
   - Absent
   - Leave
5. **Tasks**
   - Create task
   - Assign task
   - Submit task
   - Review task
6. **Performance**
   - Evaluation
   - Feedback
   - Progress
7. **Dashboard**
   - Total trainees
   - Attendance
   - Pending tasks
   - Performance
