# DTTP — Trainee Management System (TMS)

**Real-Time Project 01**

Print: [`DTTP-TMS-PROJECT.pdf`](./DTTP-TMS-PROJECT.pdf)

---

## Purpose

Build a simple system to manage Deshmukh Technologies trainees.

---

## Technology

- Python
- FastAPI
- MySQL
- React
- Git & GitHub
- Postman

---

## Main features

1. **Login** — Admin, Mentor, Trainee
2. **Trainee management** — Add, view, edit, deactivate
3. **Batch management** — Create batch, assign trainees, assign mentor
4. **Attendance** — Present, Absent, Leave
5. **Tasks** — Create, assign, submit, review
6. **Performance** — Evaluation, feedback, progress
7. **Dashboard** — Total trainees, attendance, pending tasks, performance
