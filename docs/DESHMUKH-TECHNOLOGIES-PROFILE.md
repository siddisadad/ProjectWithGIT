## Deshmukh Technologies Trainee Program

The **DTTP** is a structured **90-day Full-Stack Software Development and Professional Development Program**.

The program takes a trainee through:

```text
Orientation → Programming → Frontend → Backend → Database
   → REST APIs → Authentication → Testing → Debugging
   → Docker → CI/CD → AWS → Real Project → Production Readiness
```

Backend specialization includes **Java + Spring Boot** or **Python + FastAPI**, with **React + TypeScript** as the common frontend path.

The full program handbook is in [`DTTP-PROGRAM-HANDBOOK.pdf`](./DTTP-PROGRAM-HANDBOOK.pdf).

## Our Development Culture

> **We don't encourage developers to simply write more code. We encourage them to understand problems better and write the right code.**

A developer should be able to explain:

1. What problem are we solving?
2. Why are we solving it this way?
3. What are the alternatives?
4. What could fail?
5. How have we tested it?
6. How will we maintain it?
