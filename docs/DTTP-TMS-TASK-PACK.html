05First APIs

POST /trainees GET /trainees GET /trainees/{id} PUT /trainees/{id} DELETE /trainees/{id} GET /health

GET /health returns { "status": "ok" }.

MySQL database: dttp_tms

CREATE TABLE trainees ( id INT PRIMARY KEY AUTO_INCREMENT, full_name VARCHAR(120) NOT NULL, email VARCHAR(190) NOT NULL UNIQUE, phone VARCHAR(20), status VARCHAR(20) NOT NULL DEFAULT 'ACTIVE' );

DELETE /trainees/{id} sets status = INACTIVE. Do not remove the row.

POST /trainees example:

{ "full_name": "Rohan Deshmukh", "email": "rohan.deshmukh@example.com", "phone": "9876543210" }

Success 201. Duplicate email 409. Missing id 404.

Postman collection: docs/tms/DTTP-TMS-Task-01.postman_collection.json
